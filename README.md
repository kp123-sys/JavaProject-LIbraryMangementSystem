# BookBase Library Management System

A Java-based Library Management System developed as a group academic project using JavaFX.

## Features
- Add and manage books
- Issue and return books
- User management
- Interactive JavaFX user interface
- Organized using OOP principles

## Tech Stack
- Java
- JavaFX
- Git & GitHub

## Team Project
Developed collaboratively as part of an academic project.

## How to Run
1. Clone the repository
2. Open in IntelliJ IDEA or Eclipse
3. Configure JavaFX libraries
4. Run the main application file
